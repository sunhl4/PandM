# 经典计算化学：原理、实现路径与瓶颈

**扩展版：以合并本图 1-3 的「四分支」为研发坐标，讨论不同分子与基组下的量子介入路径**

---

## 1. 今天讲什么（**从经典问题到量子介入**）

- **起点**：经典计算化学到底在求什么，为什么从原始薛定谔方程走到今天这一整套近似方法
- **主线**：BO 电子哈密顿量 → FCI 指数墙（表 1-2）→ **四分支经典方法版图** → **每分支的发展情况、当前困境、量子可帮助的子问题、量子如何介入**
- **后半段**：用 **H₂ / H₂O(STO-3G、cc-pVDZ) / C₆H₆(cc-pVDZ)** 把这些判断落到 **比特数、活性空间、对标基线和工程边界**
- **最后几页**：不再停在抽象方法，而是讨论 **真实课题该怎么选方法、怎么做经典前端、怎么插量子模块、怎么验收**

---

## 2. 为什么公司要关心计算化学

- 催化、材料、弱相互作用等问题，往往要求达到 **1 kcal/mol 量级** 的精度，或至少能对 **激发态和近简并情形** 给出定性正确的描述
- 经典栈成熟，但 **强相关 + 大基组** 仍存在 **指数或高多项式** 子问题
- 离子阱体系具有 **全连接、长相干** 的特点，适合处理 **含大量 Pauli 项的哈密顿量采样** 和 **中等深度的变分线路**，但前提是问题已经被化学方法缩并到可处理的规模
- **与四分支对齐**：硬件与编译器的投入，应能映射到 **「在四分支的哪一条上替经典算哪一个子步、省哪一类标度」** — 避免与经典 **整条 CC 链或 KS-SCF** 无差别竞争

## 3. 电子结构问题（Born–Oppenheimer 下）

$$
\hat{H}_{\mathrm{elec}} = -\frac{1}{2}\sum_{i}\nabla_i^2
-\sum_{i,A}\frac{Z_A}{r_{iA}}
+\sum_{i<j}\frac{1}{r_{ij}}

$$

- **$\hat{V}_{ee}$**：电子–电子排斥，耦合全部电子坐标 → 一切近似的靶子

| :------------------- | :------------------------------- | :------------------------------------------- |

## 5b. 四分支为什么是今天的主线


| 图 1-3 分支           | 经典侧的主要产物                                  | 量子最自然的介入方式                                                                                                                                |
| :---------------------- | :-------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **① 波函数截断**     | 单参考波函数 + 不同激发阶的簇展开（直到 CCSD(T)） | 在**固定轨道** 上构造 **幺正簇线路**，处理 **局域电子对或局部片段哈密顿量**，并在 **同一套积分** 下与 CC 结果对比；线路深度通常与 **激发阶数** 相关 |
| **② 多体微扰**       | MPn 级数；以及**CASPT2** 这类多参考微扰方法       | 不强调「重做全空间 MP2」，而是关注**多参考零阶之后形成的有效哈密顿量块**，以及微扰步骤里 **最难对角化的子块**，必要时为 **QPE 类方法** 做准备       |
| **③ 密度泛函**       | KS 方程、交换相关泛函、双杂化中的 PT2 成分        | 量子部分通常**不直接做泛函拟合**，而是接在 **DFT 几何与轨道之后的波函数子问题**、**嵌入修正块**，或与 **双杂化中的显式 PT2 片段** 分工协作          |
| **④ 活性空间与张量** | 活性空间内的 CASCI/FCI；DMRG；Selected CI         | 这是最核心的主线：在**活性空间二阶量化哈密顿量** 上做 **VQE / ADAPT / qEOM / 资源估计**，并与 **DMRG / Selected CI / FCI** 在同一套积分下比较结果   |

- **为什么重要**：四分支不是简单的名词罗列，而是当代经典计算化学在 **复杂度、精度和可扩展性** 三个维度上形成的四条主路。量子计算若想真正进入产业问题，也必须沿着这四条已有路线切入，而不是脱离经典体系另讲一套故事

## 6. 四分支总览：经典在怎么做，量子该往哪里接


| 分支           | 核心做法                                       | 当前经典定位                                 |
| :--------------- | :----------------------------------------------- | :--------------------------------------------- |
| **波函数截断** | 在参考行列式附近加激发至 CCSD(T)               | 主族热化学高精度主力，但成本高               |
| **微扰 MPn**   | 以 HF 为参考的级数                             | 便宜、普及、适合弱相关，但参考依赖强         |
| **DFT**        | $E[\rho]$，Kohn–Sham 单粒子方程               | 大体系主力，泛函决定天花板                   |
| **活性空间**   | 人为划分活性轨道与冻结轨道，在活性空间内做 FCI | 强相关问题的主线，也与量子哈密顿量最直接对应 |

## 6A. 分支① 波函数截断（CISD → CCSD → CCSD(T)）— 经典做法、发展与困境

- **基本思路**：仍以 **HF（或 KS）单参考波函数** 为骨架，用 **激发算符簇**（单激发、双激发、三激发等）做截断；**CCSD(T)** 则在 CCSD 的基础上，用 **非迭代微扰** 的方式补入连通三激发
- **数学**：在 **全 Slater 行列式空间** 中选 **低阶连通簇子空间**；**大小一致**（CC、截断得当的 CI）优于裸 CISD
- **和 FCI 表的关系**：像 **H₂O / cc-pVTZ** 这种 **$10^{13}$** 维的全空间问题，经典上并不会真的去做全空间对角化，而是用 CC 在 **固定 $K$ 个轨道** 的前提下，尽可能逼近 **该基组内的 FCI 极限**，主要覆盖 **价层相关**；但代价仍然受到 **$O(N^7)$** 标度的限制
- **目前发展情况**：经典侧已形成 **CCSD(T)**、局域相关 **DLPNO-CCSD(T)**、近似 triples、嵌入 CC 等成熟体系，是工业高精度单点能的核心基线
- **当前困境**：一旦体系变大、基组变大，或进入 **强相关 / 多参考** 区域，单参考簇展开会同时遇到 **标度墙** 与 **参考失效** 两类问题

---

## 6B. 分支① —— 量子计算可以帮什么，怎么介入


| 分子（与合并本表一致）   | 该分支经典「主战场」                                                     | 离子阱上**可立项** 的对接对象                                                                                                                                        | **不要**对外这样讲                                       |
| :------------------------- | :------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------- |
| **H₂，STO-3G**          | 在这个空间里**CCSD 与 FCI 等价**，本质上就是一个很小的全组态相互作用问题 | 可在**JW 4 比特**（或对称约化后 **2 比特**）上，用 **UCCSD 或硬件友好型线路** 复现 **$E(R)$** 曲线；并在 **同一套积分** 下对比 **PySCF 的 `fci` 或 `ccsd`**          | 「量子算 CC 比经典更快」；这个问题经典上几乎是**毫秒级** |
| **H₂O，STO-3G，441 维** | 经典上可直接做**全 FCI**，也是展示 CC 系列相关能层次的标准教学算例       | 可在**14 比特整空间** 上做 VQE，对比 **FCI 金标准**；汇报重点应放在 **Pauli 分组数、总测量次数和 SPSA 迭代步数**                                                     | 「已经超越经典 FCI」                                     |
| **H₂O，cc-pVDZ**        | 工业上的高精度对标通常是**CCSD(T)/CBS**，而不是全轨道 FCI                | 不适合直接去“接整条 CC 链”。如果要做量子，应该把课题定义为：**从 MP2 自然占据数出发筛选活性空间，再在小空间里做簇线路或子空间求解**，并明确 **冻结芯层与轨道集合** | 「量子替代 CCSD(T) 计算水分子」，却不说明**活性空间**    |
| **C₆H₆，cc-pVDZ**      | 经典上常用**DLPNO-CCSD(T)** 等大体系近似工具                             | 更像研究型问题：把**局域电子对或局部区域** 映射成 **多个小哈密顿量块**，再做 **采样或并行 VQE**；但每个小块仍然要对标 **对应的经典小块 FCI**                         | 「离子阱直接跑整分子的 CCSD(T)」                         |

## 6C. 分支② 多体微扰（MP2 / MP4 / CASPT2）— 经典做法、发展与困境

- **MPn**：把 **相关能** 写成 **HF 为参考的级数**；**MP2** 成本 **$O(N^5)$**，对 **闭壳层弱关联** 往往 **~80% 相关能**
- **失效场景**：**参考 HF 质变差**（键断裂、简并、开壳层污染）→ MP 级数 **不收敛或定性错**
- **CASPT2**：**多参考** — 先在 **活性空间** 得 **CASSCF 零阶波函数**，再对 **动力学相关** 做 **二阶多参考微扰**；有效算子是 **$\hat{H}^{(0)}+\hat{V}$** 在 **模型空间** 上的投影
- **目前发展情况**：MP2 仍是最普及的便宜相关校正；多参考侧则演化出 **CASPT2 / NEVPT2 / XMCQDPT** 等路线，成为强相关后处理的重要工具
- **当前困境**：这条线的难点不是「公式不会写」，而是 **零阶参考选得对不对、微扰级数收不收敛、模型空间够不够好**；因此很多问题最后还是回到 **活性空间质量** 本身

## 6D. 分支② —— 量子计算可以帮什么，怎么介入


| 分子                       | 该分支经典角色                                                      | **具体** 量子接口                                                                                                                                                                            | 反例（避免空泛）                                                                         |
| :--------------------------- | :-------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| **H₂O（主族，平衡几何）** | MP2 常作为**便宜的相关能修正**，也常用于几何优化后的单点计算        | 没必要专门用量子去**重算 MP2 能量**，因为经典通常只需 **分钟级**；若要展示，也更适合作为 **教学性质的相位估计示例**                                                                          | 「量子加速 MP2」这种说法缺乏真正的业务意义                                               |
| **H₂ 拉长键**             | MP2 的参考态质量变差，因此微扰展开不再可靠                          | 应先切换到**分支④ 的 CASSCF(2e,2o)** 或直接做 **FCI**，再讨论量子介入；不要在明显失效的参考上继续叠 MP4                                                                                     | 「MP4+量子」但前面的参考问题都没解决                                                     |
| **H₂O，cc-pVDZ**          | 动态相关通常靠**MP2/CC**，局部强相关则进入 **CASSCF+CASPT2**        | 更合理的量子切入点，是放在**CASPT2 之前的 CASCI / 有效哈密顿量构造** 上，例如求 **(8e,8o) CASCI 矩阵块** 的 **基态和若干低激发态**                                                           | 把**整个 CASPT2** 说成“上阱一次算完”；像 **IPEA/DIPEA** 和各种收缩方案仍然属于经典部分 |
| **C₆H₆**                 | 对**π 激发态或多态问题**，常见路线是 **SA-CASSCF + CASPT2/NEVPT2** | 在**固定 SA-CASSCF 轨道** 的前提下，对 **选定的少数态模型哈密顿量**（并明确说明所属对称性）做 **qEOM 或 subspace VQE**；此时比特数由 **活性轨道数** 决定，而不是由 **114 个全轨道** 直接决定 | 「量子计算苯的 CASPT2」，却不说明**轨道是否冻结、模型空间如何定义**                      |

## 6E. 分支③ 密度泛函（LDA / GGA / Hybrid / 双杂化）— 经典做法、发展与困境

- **核心思路**：理论上，基态能量可以写成密度泛函 $E[\rho]$；在实际计算中，通常通过 **Kohn-Sham 方程** 引入一个无相互作用参考体系，再把未知的 **交换相关能** $E_{\mathrm{xc}}[\rho]$ 用近似泛函表示（**杂化泛函** 会混入一部分 **HF 交换**，**双杂化** 还会进一步混入 **PT2 成分**）
- **与波函数分支关系**：**双杂化** 已把 **「MP2 型相关」** 写进泛函；**DFT 不给出 FCI 维数意义上的波函数**
- **目前发展情况**：LDA → GGA → meta-GGA → 杂化 → 双杂化，已覆盖从材料到分子的大量工作流；工业上几何、筛选、频率、反应趋势很多时候首先靠 DFT
- **当前困境**：最核心不是标度，而是 **泛函误差不可系统消除**；强相关、长程色散、反应势垒、激发态和电荷转移问题常需要回到波函数或多参考方法补救

---

## 6F. 分支③ —— 量子计算可以帮什么，怎么介入


| 分子              | DFT 在流水线中的位置                                                        | **具体** 量子接口（第一性原理语境）                                                                                                                                                                            | 必须写清的**断层**                                                                       |
| :------------------ | :---------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| **H₂O**          | 常见流程是先用**B3LYP/PBE0** 优化几何，再转向 **波函数方法** 做更高精度计算 | 量子部分通常**不负责 KS 自洽本身**；它读入的是 **DFT 已收敛几何** 下重新生成的 **HF/CASSCF 积分**。如果展示 **H₂O 的角势能面**，应把 **所用泛函和数值网格** 写清楚                                            | 「量子改进了 B3LYP」，但并没有引入新的**交换相关参数化**                                 |
| **H₂O，cc-pVDZ** | **SCAN、ωB97X-V** 这类泛函常用于判断 **弱相互作用趋势**                    | 量子部分并不能直接替代**长程色散描述**；更合适的说法是做 **“DFT 几何 + (8e,8o) CASCI”** 的混合流程，并把误差拆成 **几何误差** 和 **活性空间对角化误差** 两部分                                               | 把**CAS 能量** 直接叫成 **“DFT 能量修正”**                                             |
| **C₆H₆**        | 苯的**气相几何、振动频率和环伸缩模式** 常常先用 DFT 处理                    | 可先固定**DFT 平衡几何**（如 **$D_{6h}$**），再做 **Pipek–Mezey 局域化**，选出 **π / π\*** 轨道组成 **CASSCF(10e,8o)**，最后把对应的 **CASCI 哈密顿量** 交给量子部分处理；此时比特数大约在 **16 比特** 左右 | 若上机的是**Hubbard / PPP** 这类模型，就必须明确说明它 **不是表 1-2 中的第一性原理 FCI** |

## 6G. 分支④ 活性空间与张量（CASSCF / DMRG / Selected CI）— 经典做法、发展与困境

- **基本思想**：把 **指数复杂度** 限制在 **$(N_{\mathrm{act}},M_{\mathrm{act}})$** 这个较小的子空间里：**CASSCF** 负责优化活性轨道，**CASCI / 活性空间 FCI** 负责在活性空间内求解，**DMRG** 用 **MPS** 表示压缩纠缠，**Selected CI** 则通过重要性采样挑选关键行列式
- **与量子信息的对应关系**：经过 **二阶量化 + JW/BK/parity 映射** 后，**活性空间 FCI** 本质上就变成了一个 **有限维 Pauli 哈密顿量的基态问题**
- **目前的发展情况**：这条路线已经成为处理 **强相关、近简并、断键、过渡金属和激发态** 的经典主轴；与此同时，DMRG、Selected CI 和各类嵌入方法也在不断抬高经典基线
- **当前困境**：真正难的地方不只是求解器本身，而是 **活性空间怎么选、轨道怎么局域化、bath 怎么构造、动力学相关怎么补**；也正因为最后会落成一个有限维哈密顿量，它才最容易和量子计算形成实质性的接口

## 6H. 分支④ —— 量子计算可以帮什么，怎么介入（最「硬」对接表）


| 分子（表 1-2）      | Active 典型标签（**须写进任务书**）                      | Hilbert 维数 / 比特（量级）                                   | **经典对标命令级目标**                                                 |
| :-------------------- | :--------------------------------------------------------- | :-------------------------------------------------------------- | :----------------------------------------------------------------------- |
| **H₂，STO-3G**     | 活性空间就是**全轨道**                                   | **$D=4$**；JW **4 比特**（或对称约化为 **2 比特**）           | 用`fci` 或手算结果与量子结果做到 **逐 mH 对齐**                        |
| **H₂O，STO-3G**    | 可取**全 7 轨道 10e**，也可做 **冻结芯层 + CAS(8e,6o)**  | **441**，或 **$\binom{6}{4}^2=225$** 等                       | 在**同一几何结构** 下，对标 `FCI()` 或 `CASCI`                         |
| **H₂O，cc-pVDZ**   | 示例可设为**CAS(8e,8o)**                                 | $\binom{8}{4}^2=4900$；对应 **16 个自旋轨道**，约 **16 比特** | 量子端与 PySCF 的 CASCI 共用**同一套** `h_pq`、`h_pqrs` 积分文件       |
| **C₆H₆，cc-pVDZ** | 在嵌入后的小块上做**CAS(6e,6o)**（约 **$\sim 400$** 维） | **12 个自旋轨道**                                             | 让**DMET/QMMM** 产生的经典小块与量子端共用同一个哈密顿量，再对标 CASCI |

- **离子阱的优势也要落到具体任务上**：**全连接结构** 有利于按 **可交换的 Pauli 项集合** 来安排测量；**长相干时间** 有利于在 **同一哈密顿量** 上做持续标定；真正的成功判据仍应写成：**与上表中的经典基线相比，能量误差低于阈值（如 1 mH 或相应的 kcal/mol），并同时给出测量预算**

---

## 7. 算例 A：H₂（2e，STO-3G，$K{=}2$，$D_{\mathrm{FCI}}{=}4$）— 经典在做什么

- **承接 §6B / §6H**：在分支①里 **CCSD = FCI**，在分支④里 **活性空间就是全轨道**；本页把 **维数与势能曲线** 讲得更具体
- **极小基**：每个 H 对应一个收缩高斯型基函数，共 **2 个空间轨道**；2 个电子闭壳层时，**全组态相互作用空间只有 4 个 Slater 行列式**，如果只看单重态子空间还会更小
- **HF**：平衡键长附近尚可；**键拉长** 时单行列式失效 → **静态相关**（合并本 §1.3）
- **后 HF 方法**：这里的 FCI 就是标准答案；而 CCSD(T) 在这样一个极小空间里也会与 FCI 重合，本质上仍是一个非常小的全组态相互作用问题

---

## 8. 算例 A：H₂ — 量子计算**具体**能做什么（离子阱语境）

- **哈密顿量尺寸**：二阶量化后 **4 个自旋轨道** → Jordan–Wigner **4 比特**（可用 **粒子数守恒 / $S_z$ 对称** 压缩到 **2 比特** 表示单重态块，视编码而定）
- **可执行实验（非泛泛）**：
  1. **VQE / UCC** 或 **HEA**：参数量通常只有 **个位数到十余个**；可直接对比 **经典 FCI 势能曲线 $E(R)$**（按不同键长 $R$ 扫描），并把误差拆成 **采样误差、读出误差和门误差**
  2. **在断键区域**：必须允许 **双激发** 成分进入波函数；常见 UCCSD 的线路深度大致对应 **$\mathcal{O}(n^2)$ 的两比特门层数**。离子阱的全连接有助于 **并行安排 CNOT**，但整体深度仍然受 **相干时间** 限制，因此它更适合作为 **硬件标定和误差缓解** 的化学入门算例
  3. **不适合的说法**：不要说这是 **QPE 加速** 的例子，因为经典上 **4×4 对角化** 已经是精确且极快的；它真正的价值在于 **验证量子化学编译链条**（OpenFermion → Pauli 分组 → 量子设备）
- **建议的对接指标**：每个几何点与 FCI 的能量差控制在 **化学精度 1 kcal/mol** 对应的 Hartree 量级以内；把它作为 **内部里程碑**，比直接宣称“展示量子优越性”更稳妥

---

## 9. 算例 B：H₂O（10e，STO-3G，$K{=}7$，$D{=}441$）— 经典在做什么

- **全空间 FCI**：**441** 维，笔记本 **稠密对角化** 秒级；是 **教学与基准** 的「小体系、可全 FCI」标准例
- **HF → MP2 → CCSD(T)**：在此基组下主要展示 **方法层次** 与 **相关能占比**；**几何** 仍偏粗糙（基组太小）
- **意义**：**量子算法正确性** 可用 **全空间 FCI** 作 **金标准**（在同一 7 轨道模型内）

---

## 10. 算例 B：H₂O(STO-3G) — 量子计算**具体**能做什么

- **如果坚持使用全 7 个轨道、10 个电子**：则对应 **14 个自旋轨道**，经 JW 映射后需要 **14 比特**；哈密顿量会展开成 **$\mathcal{O}(K^4)$** 量级的 **Pauli 串求和**（实际项数还会受对称性化简影响）
- **离子阱上可定义的任务**：
  1. **VQE 基态能** 对比 **PySCF FCI**（同一几何、同一套积分），重点统计 **Pauli 项数、分组后的总测量次数** 以及 **收敛迭代步数**
  2. **子空间压缩**：例如冻结 **氧 1s 芯层** 后得到 **8e in 6o** 之类的问题；这时需要在报告之外先固定一种轨道选择方式（如 **canonical** 或 **Pipek-Mezey**）。对应的 CASCI 维数会变成 $\binom{6}{4}^2=225$，经典上仍可全对角化，量子侧则适合做 **中等比特规模的标定**
  3. **不要声称**：在 STO-3G 上「量子超越经典」— 经典 FCI **已精确**
- **适合汇报的工程指标**：Pauli 项数、**总测量预算**、**CNOT 数量**，以及相对于 FCI 的 **系统误差和统计误差** 对比图

---

## 11. 算例 C：H₂O（10e，cc-pVDZ，$K{=}24$，$D{\sim}1.8\times 10^7$）— 经典在做什么

- **全 FCI**：$\sim 10^7$ 维 — **一般实验室不做全 FCI**；工业界用 **DFT 几何优化 + MP2/CCSD(T) 单点** 等组合
- **「化学精度」** 常指 **大基组 + CCSD(T)** 或 **CBS 外推**，与「全空间 FCI」不是同一目标
- **活性空间经典**：例如选 **8 个空间轨道、8 电子** 闭壳层 CAS：$\binom{8}{4}^2=4900$ 维 CASCI — **笔记本电脑稠密对角化仍可行**；这是 **量子演示与经典「强基线」重叠区**

---

## 12. 算例 C：H₂O(cc-pVDZ) — 量子计算**具体**能做什么

- **缩并模板**（项目中必须先固定轨道和电子数）：
  - 例：**CAS(8e, 8o)** → **16 自旋轨道** → JW **16 量子比特**（**parity taper / $Z_2$ 对称** 常可减 **1–2** 比特，视对称性实现）
  - **哈密顿量**：采用二阶量化形式，**积分从 PySCF / ORCA 导出**；**Pauli 项数** 通常在 **数千到数万** 的量级（经对称性化简后），很适合讨论 **分组测量与测量复杂度**
- **离子阱可陈述的「真任务」**：
  1. 在 **固定核几何** 下求 **CASCI 基态能量**，对标 **同一活性空间** 下的经典 FCI / CASCI（而不是直接和全分子、全轨道的 CCSD(T) 比，除非你已经把 **嵌入误差** 单独说明）
  2. 若要做 **势能面**，可以扫描多个 **O-H 键长**，在每个几何点重复 VQE，再汇报 **总测量预算 × 几何点数** 与 **经典 CCSD(T) 单点成本** 的对比；但要老实说明：二者本质上仍是 **不同模型**
  3. 若关注 **激发态**，可以在同一 CAS 哈密顿量上用 **subspace VQE / qEOM** 求前几根，再对标 **PySCF 的态平均 CASSCF + CASCI** 或活性空间内的 FCI
- **不能声称**：「量子机解了 cc-pVDZ 全轨道的 10 电子问题」— 表内 **$1.8\times 10^7$** 维仍宜 **选 CI / DMRG** 经典处理

---

## ※ 表行补充：H₂O（cc-pVTZ，$K{=}58$，$D\sim1.5\times10^{13}$）

- **经典**：通常**不会做全 FCI**；而是用 **CCSD(T)**、显式相关方法和局域相关技术去逼近基组极限。遇到强相关时，则会在 **轨道子集** 上使用 **DMRG / Selected CI**
- **量子（具体）**：与 cc-pVDZ 的处理思路相同，**活性空间仍然需要人为缩小**；VTZ 带来的变化主要有两点：**(i)** 积分生成和轨道选择对 **CPU/GPU** 的压力更大，**(ii)** 如果从更宽的能谱中选活性轨道，那么即便都写成 **(8e,8o)**，其轨道内容也可能与 VDZ 情况不同，因此 **两者能量不能直接横向比较**
- **边界**：面对 **$10^{13}$ 维的全空间问题**，NISQ 没有现实路径；对外汇报时必须说明 **“量子比特数 = 2 × 活性空间轨道数”，而不是和 58 个全轨道直接画等号**

---

## 13. 算例 D：C₆H₆（42e，cc-pVDZ，$K{=}114$）— 经典在做什么

- **全 FCI 维 $\sim 10^{51}$**：**任何**全空间对角化都不可能；实际用 **DFT / 杂化泛函** 做几何与振动，相关能用 **DLPNO-CCSD(T)、局部相关、多体嵌入**
- **强相关片段**：芳环的 **π 共轭** 可以在 **多参考** 框架下，用 **(π,π\*) 活性空间** 描述部分 **激发态和双自由基特征**，但前提仍是先从全基组里把问题 **缩并** 出来

---

## 14. 算例 D：C₆H₆(cc-pVDZ) — 量子计算**具体**能做什么

- **整分子 114 轨道全电子**：**不适合**作为 NISQ 目标；应绑定 **经典嵌入产物**：
  1. **DMET / QM/MM / ONIOM**：把环境压成 **bath 轨道**，在 **2 个相邻 C 原子 + 配位 H** 等 **QM 簇** 上取 **CAS(6e,6o)** 量级：$\binom{6}{3}^2=400$ 维 — **经典 CASCI 极易**，量子价值在 **与真实嵌入流水线的接口演示** 或 **多碎片并行**（若公司有 **多机** 规划）
  2. **低维模型哈密顿量**：例如 **Hubbard / PPP** 只保留 **π 电子**。这类问题 **不是** 表 1-2 中的 **第一性原理 FCI**；如果上量子机，必须明确标注为 **“模型哈密顿量”**，并用 **缩并误差** 与第一性原理结果建立联系
  3. **激发态 / 光谱问题**：可以先用 **TD-DFT** 选出少数目标根，再转成 **小活性空间里的 LR-CC / EOM** 子问题；此时量子模块可定义为 **固定维数的 CI 矩阵块对角化**，但需要和理论化学同事先把 **目标态和对称性** 说清楚
- **和离子阱硬件的对应关系**：**长相干时间** 适合在 **同一个哈密顿量** 上做多轮 VQE 标定；**全连接结构** 则有利于按 **可交换的 Pauli 分组** 设计并行读出方案，但最终仍要和测量预算一起评估

## 15. 变分原理（全局骨架）

$$
\langle\tilde{\psi}|\hat{H}|\tilde{\psi}\rangle \geq E_0

$$

- **HF、截断 CI、CASSCF** 等：**变分**；**CC、MP** 一般 **非变分** 但有 **大小一致性** 等优势

---

## 16. 基组与 LCAO

$$
\phi_i(\mathbf{r}) = \sum_\mu c_{\mu i}\,\chi_\mu(\mathbf{r})

$$

- **基组越大**，表 1-2 中的 **$K$** 就越大，FCI 维数也会迅速爆炸；因此量子侧通常要先借助经典方法，通过 **选轨道、AVAS 或 DMET** 等步骤，把 **$K$** 缩成远小于它的 **$M_{\mathrm{act}}$**

---

## 17. Hartree–Fock 与 SCF

- **单 Slater 行列式** + **Fock 平均场** + **$\mathbf{FC}=\mathbf{SC}\boldsymbol{\varepsilon}$**；**SCF** 为不动点迭代
- **双电子积分**：**$\mathcal{O}(K^4)$**；Fock 构建 **$\mathcal{O}(K^4)$** 或借助 **积分筛选** 降低

## 23. 实际问题怎么做 I：先判断问题属于哪一类

1. **目标是什么**：基态能量、相对能、势能面、激发态，还是筛选几何与趋势
2. **相关类型是什么**：弱相关 / 动态相关为主，还是断键、近简并、开壳层这类静态相关
3. **体系规模如何**：是小分子、追求高精度；还是中等体系、还能做活性空间；又或者已经大到只能依赖嵌入和筛选方法
4. **据此选主分支**：弱相关主族先看 **DFT / MP2 / CC**；强相关问题优先看 **活性空间 + 后处理**

---

## 24. 实际问题怎么做 II：经典前端如何准备

1. **几何与初猜**：常先用 **DFT** 或 HF 做几何、频率、初猜轨道
2. **轨道与基组**：先把 **基组、是否冻结芯层、轨道局域化方式** 以及是否采用 **AVAS / Pipek-Mezey / Boys** 等方案确定下来
3. **相关框架**：如果是弱相关主族体系，经典主线往往是 **DFT → MP2 / CCSD(T)**；如果是强相关问题，则应转向 **CASSCF / DMRG / Selected CI**
4. **在量子介入前必须固定**：**几何结构、基组、轨道集合、活性电子数 / 轨道数，以及积分文件**；否则量子结果就没有可比性

---

## 25. 实际问题怎么做 III：量子计算怎么介入

1. **不要直接去接原始的化学问题**；应该先接 **经典方法已经缩并好的对象**，例如 **活性空间哈密顿量、片段哈密顿量**，或者某个固定的子空间矩阵块
2. **典型插入点**：
   - **DFT 后**：用 DFT 几何与轨道作为前端，再做 **CASCI / VQE**
   - **CASSCF / DMRG 后**：把最难的 **活性空间 FCI** 或低激发态求解交给量子
   - **嵌入框架内**：在 **DMET / QM/MM / ONIOM** 给出的局部块上做量子求解
3. **量子输出不是终点**：通常还需要 **RDM 回写、总能量拼装、动态相关校正**，并重新接回经典后处理流程

---

## 26. 实际问题怎么做 IV：怎么判断量子介入有没有价值


| 判断项                           | 应该问什么                                                              |
| :--------------------------------- | :------------------------------------------------------------------------ |
| **经典是否已经够好**             | 若 DFT / MP2 / CCSD(T) 已满足业务精度，是否还有必要上量子               |
| **困难是否真的在活性空间子问题** | 若真正的难点在泛函误差、溶剂效应或构象搜索，量子未必是第一优先级        |
| **量子块是否可对标**             | 是否有**同一活性空间、同一套积分** 下的 CASCI / DMRG / Selected CI 基线 |
| **成本是否可汇报**               | 是否能同时给出**比特数、Pauli 项数、测量预算、线路深度和总耗时**        |
| **结果是否可回写业务**           | 能否转成相对能、势垒、谱线、筛选指标，而不只是一个孤立能量值            |

---

## 27. 实际问题怎么做 V：建议的项目落地模板

1. **问题定义**：分子 / 材料、性质、目标精度、几何来源
2. **经典主分支**：四分支里当前主路是哪条，为什么现有方法在这里不够
3. **量子插入点**：活性空间、局部片段或目标子空间到底是什么，输入和输出分别是什么
4. **对标基线**：在 PySCF / ORCA / block2 / Selected CI 中，究竟选哪一个模块作为金标准
5. **验收指标**：误差（mH 或 kcal/mol）、资源消耗（比特数 / 测量预算 / 线路深度）以及稳定性（多几何点 / 多态）
6. **对外表述**：明确写清 **「解的是哪个缩并后的哈密顿量」**，避免夸大成“量子求解整个分子”

---

## 28. 结论

1. **经典出发点** 是同一个多电子问题，但今天主要演化成 **四条经典路线**：波函数截断、微扰、DFT、活性空间
2. **每条路线都已经相当成熟**，但也各自有明显天花板：**CC 受标度限制，MP 依赖参考态质量，DFT 受泛函误差影响，而活性空间方法则受选轨和嵌入质量制约**
3. **量子计算真正有机会的地方**，不是抽象地“加速量子化学”，而是 **进入这些经典路线已经定义好的难子问题**
4. **实际项目落地** 必须回答四件事：**经典主线是什么、困难在哪、量子接哪一块、怎么与经典基线和业务指标闭环**
